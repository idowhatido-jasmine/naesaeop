# 법적·정책 점검

| 항목 | 점검 결과 |
|---|---|
| 의료·건강 표현 | 치료·예방·효과 보장 표현을 사용하지 않았습니다. 통증 지속, 붓기, 저림에는 의료진 상담을 안내했습니다. |
| 후기 인용 | 1주~1개월 언급은 사용자 제공 자료에 근거해 `사례`, `개인차`로 한정했습니다. 모든 사용자에게 같은 결과를 보장한다는 표현은 없습니다. |
| 판매 수치 | OEM 포함 100만 개 이상은 사용자 제공 내부 판매 기록으로 출처를 명시했습니다. 외부 검증 수치로 표현하지 않았습니다. |
| 이미지 | 본문 이미지 6장은 AI 생성 이미지이며, 로고·인물 식별 정보·제3자 저작물을 포함하지 않도록 생성했습니다. |
| 광고·이해관계 고지 | 자사 제품과 후기를 언급하는 홍보성 게시물이라면, 실제 게시 목적과 채널 정책에 맞춰 발행 전 눈에 잘 띄는 위치에 광고 또는 경제적 이해관계 고지 문구를 추가하세요. |
