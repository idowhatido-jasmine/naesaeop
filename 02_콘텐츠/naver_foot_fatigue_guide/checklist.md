# 제작·발행 체크

## 검색/AEO형 판단
- 모드: 검색/AEO형
- 판단 근거: 발 통증 관리 방법과 사용 기간을 묻는 정보형 질문이며, 결론·수치·FAQ 구조가 검색 의도에 맞음
- 카테고리: 건강관리 / 풋헬스
- 독자: 오래 걷거나 서 있을 때 발 통증과 피로를 느끼는 사람

## 법적·정책 리스크 점검
| 항목 | 결과 |
|---|---|
| 사진 저작권 | 해당 없음 — 외부 사진·기사 이미지를 사용하지 않고 AI 생성 이미지 사용 |
| 초상권·퍼블리시티권 | 해당 없음 — 식별 가능한 실존 인물 미사용 |
| 명예훼손 | 해당 없음 |
| 의료·식품 광고 | 수정함 — 치료·예방·효과 보장 표현을 제거하고, 개인차와 진료 권고를 명시 |
| 대가성 표기 | 사용자 확인 필요 — 협찬·제공·판매 수수료 등 경제적 이해관계가 있으면 네이버 글 첫 부분에 정확한 표기 추가 |
| AI 산출물 고지 | 수정함 — 각 이미지에 ‘AI 생성 이미지’ 캡션을 넣음 |

## 발행 체크
- [ ] 제목과 본문을 스마트에디터에 옮기고 소제목·강조 서식 확인
- [ ] 썸네일 01-thumbnail.png, 본문 이미지 02~05를 순서대로 삽입
- [ ] 편집용 HTML의 이미지 자리표시자를 실제 이미지로 교체
- [ ] 이미지 번호·파일명·삽입 안내 문구를 발행 본문에서 제거
- [ ] 모바일 미리보기에서 문단 간격·이미지 배치 확인
- [ ] 태그 입력: tags.txt의 # 없는 한 줄 사용
- [ ] 카테고리·공개 범위 확인 후 사람이 직접 발행
- [ ] 유사문서율 확인 및 발행 로그 1줄 기록

자동 발행은 하지 않았습니다.
